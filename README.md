The circuits are designed and simulated using Logisim / Logisim Evolution, with AI-assisted tools used in selected experiments for design exploration and explanation.

✨ Highlights
- Boolean logic design: Simplification and implementation of Boolean functions.
- FSM-based systems: Traffic light and automatic parking barrier controllers.
- Sequential circuits: Flip-flops, counters, and shift registers.
- Digital system design: A digital clock and a 4-bit Mini-ALU.
- Simulation and verification: Circuit behaviour checked using Logisim.
- AI-assisted learning: Selected experiments use ChatGPT/Gemini for design support and explanations.
